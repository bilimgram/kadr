# Getting help

- **Questions and ideas:** GitHub Discussions.
- **Bugs:** open an issue with the bug report template (version, OS, steps to reproduce).
- **Security vulnerabilities:** never in public — follow [SECURITY.md](SECURITY.md).
- **Contributing:** start with [CONTRIBUTING.md](CONTRIBUTING.md) and
  [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

Commercial support for Kadr Cloud and Enterprise will be listed here when those editions launch.
